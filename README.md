Chi-Square Test Using Python

📌 Project Overview

This project demonstrates the application of Chi-Square statistical tests using Python. It focuses on identifying relationships between categorical variables and comparing observed frequencies with expected frequencies.

The project includes practical examples of Chi-Square Test for Independence and Chi-Square Goodness of Fit using statistical calculations and hypothesis testing.

🎯 Objectives

* Understand the concept of Chi-Square testing.
* Identify relationships between categorical variables.
* Perform Chi-Square Test for Independence.
* Perform Chi-Square Goodness of Fit testing.
* Calculate Cramér’s V to measure association strength.
* Interpret p-values and statistical results.

📊 Key Analysis and Results

1. Chi-Square Test for Independence

* Analyzed the relationship between occupation and neighbourhood of residence.
* Obtained Chi-Square Statistic: 24.5712.
* p-value: 0.0004.
* Degrees of Freedom: 6.
* Cramér’s V: 0.1375 (Small association).

Result: Rejected the null hypothesis, indicating a statistically significant association between occupation and neighbourhood.

2. Chi-Square Goodness of Fit

* Analyzed customer visits across five weekdays.
* Observed a total of 250 customers.
* Obtained Chi-Square Statistic: 4.3600.
* p-value: 0.3595.
* Degrees of Freedom: 4.

Result: Failed to reject the null hypothesis, indicating insufficient evidence against an equal distribution of customers across weekdays.
